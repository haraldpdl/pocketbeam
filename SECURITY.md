# Security

pocketbeam runs on your e-reader and talks to servers you configure. It
stores your server password in plain text in its config file on the
device, which is the same trust model as the stock PocketBook apps.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting on this repository
("Security" tab → "Report a vulnerability") rather than a public issue.
You should get a first response within a week.

## Supported versions

Only the latest release is supported. The app checks for updates weekly
(configurable) and installs them on request.
